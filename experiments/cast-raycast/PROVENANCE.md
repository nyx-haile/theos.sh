# Provenance

This directory preserves the standalone **Cast: raycast kerning prototype** found at `/home/lunaris/build/kerning` on 2026-07-24.

The source directory had no usable Git history at import time, so there is no upstream commit identifier to record. Its complete application source, documentation, package metadata, development server, and 13 Node geometry tests are preserved here.

Cast is a historical control experiment for silhouette-contact spacing. It is intentionally isolated from `src/scribe/`; the Scribe engine and playground must not import or depend on it.

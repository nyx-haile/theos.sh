# Sample content

This folder holds sample Markdown used to keep forks free of private posts. Copy it to `content/` or point the publish script at your own private content repo during CI.

Structure:
- `posts/YYYY-MM-DD-slug.md`
- `notes/YYYY-MM-DD-slug.md`
- `projects/slug.md`
- `pages/about.md`, `pages/now.md`

Each file requires frontmatter with at least `title`, `date`, and `type`, plus tags and summary where relevant. Images must include alt text.
